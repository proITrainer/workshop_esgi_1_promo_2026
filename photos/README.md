# Dossier des photos

Deposez ici votre photo (facultatif), au format `.jpg` ou `.png`.

- Nommez le fichier simplement, par exemple : `prenom-nom.jpg`
- Indiquez ce meme nom dans le champ `photo:` de votre fiche (`_promo/prenom-nom.md`)
- Si vous ne mettez pas de photo, vos initiales s'afficheront automatiquement
  dans un joli rond aux couleurs de l'ecole.

Conseil : une image carree (ex. 400x400 px) rend le mieux.
