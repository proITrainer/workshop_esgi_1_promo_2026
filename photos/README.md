# Dossier des photos

Déposez ici votre photo (facultatif), au format `.jpg` ou `.png`.

- Nommez le fichier simplement, par exemple : `prenom-nom.jpg`
- Indiquez ce même nom dans le champ `photo:` de votre fiche (`_promo/prenom-nom.md`)
- Si vous ne mettez pas de photo, vos initiales s'afficheront automatiquement
  dans un joli rond aux couleurs de l'école.

Conseil : une image carrée (ex. 400x400 px) rend le mieux.
